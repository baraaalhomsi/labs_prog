# Лабораторная работа 3 — Python RPG

Текстовая RPG, реализующая пять обязательных порождающих паттернов:
Singleton, Builder, Factory Method, Abstract Factory и Prototype.

## Требования
- Python 3.10+
- Сторонние библиотеки не нужны.

## Запуск
Из корневой папки проекта:

```bash
python -m labs.lab3.demo
python -m labs.lab3.main
```

## Структура
- `core` — единый генератор случайных чисел и исключения.
- `combat` — абстракция участника боя, события и симуляция раундов.
- `items` — предметы, каталог прототипов, копирование и зачарования.
- `kits` — Abstract Factory для стартовых комплектов.
- `hero` — классы героя и Builder.
- `enemies` — типы противников.
- `world` — локации, Factory Method, экспедиции и реестр локаций.
- `camp` — торговец.
- `console_view.py` — отображение состояния и отчётов.
- `demo.py` — отдельная демонстрация пяти паттернов.
- `main.py` — игровой цикл.

## Что показать на защите
1. Singleton: `Dice() is Dice()` выводит `True`.
2. Builder: создание героя цепочкой вызовов `HeroBuilder`.
3. Factory Method: `Forest` и `Crypt` создают разные классы противников.
4. Abstract Factory: фабрики воина и следопыта создают разные пары продуктов.
5. Prototype: копия предмета получает своё зачарование, оригинал остаётся прежним.

Рекомендуется перед сдачей самостоятельно прочитать классы и быть готовым объяснить,
почему каждый паттерн применён именно в этом месте.
